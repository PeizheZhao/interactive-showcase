连接课程空间

网站只保存显示偏好和连接配置。笔记与访问令牌不会写入仓库或本地存储。

第一次配置：跟着这 5 步完成
  1. 打开 Google Cloud Console，创建或选择你自己的项目。
  2. 启用 Google Drive API。在 Google Auth Platform 中配置应用信息、受众；个人试用可保持 Testing，并把自己的 Google 邮箱加入 Test users。
  3. 创建 Web application 类型的 OAuth Client。把下方域名加入 Authorized JavaScript origins：。填域名，不填网站路径。
  4. 使用只读权限 https://www.googleapis.com/auth/drive.readonly。该权限允许读取你账号可访问的 Drive 文件，并非仅限所选文件夹；阅读器自身只浏览你指定的目录。个人自用不需要 client secret，也不需要 API key。
  5. 将 Client ID 粘贴到上方，保存并连接。每次浏览器会话登录授权；令牌过期后点击重新连接。

Google 账号登录必须在普通浏览器内进行。若学校账号限制第三方应用，请使用有该资料访问权限的个人账号，或使用本地文件阅读。
